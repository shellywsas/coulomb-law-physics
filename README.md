# ⚡ אתר לימוד חוק קולון וחשמל סטטי (פיזיקה י״ב - 5 יח״ל)

אתר לימודי אינטראקטיבי מקיף, מעוצב בצבעי פסטל בהירים ומרגיעים, המיועד לתלמידי כיתה י״ב להכנה לבגרות בפיזיקה בחשמל ומגנטיות (אלקטרוסטטיקה).

---

## 🌟 תכונות מרכזיות באתר

1. **📖 תיאוריה מעמיקה והסברים ברורים:**
   * ניסוח חוק קולון (\(F = k \frac{|q_1 q_2|}{r^2}\)) ומשמעות קבוע קולון והמקדם הדיאלקטרי של הריק (\(\varepsilon_0\)).
   * כיוון הכוח, משיכה/דחייה והדגשת החוק השלישי של ניוטון (\(\vec{F}_{1\to 2} = -\vec{F}_{2\to 1}\)).
   * השוואה מלאה בין חוק קולון לחוק הכבידה העולמי של ניוטון.
   * עקרון הסופרפוזיציה עם שלבי עבודה לפתרון שאלות מורכבות בבגרות.

2. **🔬 סימולטור ויזואלי אינטראקטיבי (Canvas):**
   * שינוי מטענים (\(q_1, q_2\)) ומרחק (\(r\)) באמצעות סליידרים.
   * תצוגת חצי כוח וקטוריים חיים המשתנים בגודלם ובכיוונם בזמן אמת.
   * כפתור מהיר להדגמת משיכה בין מטענים מנוגדים.

3. **🧮 מחשבון שלבי הצבה:**
   * המרת יחידות אוטומטית ליחידות תקניות (SI).
   * הצגת הנוסחה המדויקת עם המספרים שהוזנו.
   * תוצאה סופית מדויקת בניוטונים (N) וסיווג אופי הכוח (משיכה/דחייה).

4. **📝 תרגילים פתורים ברמת בגרות:**
   * 3 תרגילים טיפוסיים (חישוב בסיסי ושיתוף מטען במגע, מציאת נקודת איפוס כוח, וכוח שקול במשולש בדו-ממד).
   * כפתורי חשיפת פתרון מודרך שלב-אחר-שלב.

5. **🎯 בוחן ידע אמריקאי אינטראקטיבי:**
   * 5 שאלות מושגיות וחישוביות לבדיקה עצמית.
   * בדיקה אוטומטית עם משוב, ציון והסבר מפורט לכל שאלה.

6. **🖨️ הדפסה ושמירה כ-PDF בלחיצה אחת:**
   * כפתור ייעודי שמעצב את כל החומרים לדפי עבודה וסיכום נקיים בפורמט A4.
